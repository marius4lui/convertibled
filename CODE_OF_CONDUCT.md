# Code of conduct

Treat contributors and users respectfully. Critique ideas and code, not people.
Harassment, threats, discriminatory abuse, disclosure of private information,
and persistent disruptive behavior are unacceptable.

Maintainers may edit/remove disruptive content, limit participation, or ban
participants proportionately. Reports concerning conduct can be raised with
the repository maintainer; request a private contact without publishing personal
information when no private channel is available. Maintainers should protect
reporter privacy and avoid conflicts of interest in enforcement.

This is a project-specific policy, not a claim of adopting an external standard.
